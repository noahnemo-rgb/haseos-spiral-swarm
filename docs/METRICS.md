# Measures listed, not collected

These are reserved measures. They name what health would look like. They are not a live system. This page does not take measurements.

Vanity is not health. Stars, clone counts, infants-per-hour, token volume, and Seal impressions are not listed here as success.

**Charter**

- `ratified` remains false until HITL says otherwise

**Stamp**

**Roster**

- `fusion_true` must stay 0

**Workshop**

- `witness_chain_gaps` (target 0)
